# NimiqEarn Quest Supporting Document

## Project Title

NimiqEarn Quest: AI-Powered Telegram Task and Bounty Marketplace for the Nimiq Ecosystem

## Purpose of This Document

This document supports the Nimiq ecosystem proposal for NimiqEarn Quest. It provides a clear summary of the project's problem statement, MVP scope, expected ecosystem impact, delivery timeline, and execution readiness.

## Project Summary

NimiqEarn Quest is a Telegram-native microtask and bounty marketplace built to increase Nimiq adoption through real user activity. Users complete tasks inside Telegram and receive instant NIM rewards, while startups, communities, creators, and Web3 teams use the platform to distribute tasks, campaigns, and bounties.

The MVP combines:

- Telegram bot infrastructure
- Nimiq wallet onboarding
- instant NIM payouts
- AI-assisted task verification
- reputation and referral mechanics

## Problem Statement

Many existing task platforms are difficult for mobile-first users, especially in emerging markets. They often depend on banking rails, have delayed payouts, and create friction during onboarding.

At the same time, Web3 communities need lightweight systems to:

- grow users
- reward participation
- recruit contributors
- test products
- run bounty campaigns

NimiqEarn Quest addresses both sides by creating a simple earning layer inside Telegram with NIM as the reward rail.

## Why This Fits the Nimiq Ecosystem

This project is designed to create direct utility for NIM through frequent real-world reward activity. Instead of positioning NIM only as a speculative asset, the product uses it as an operational payment currency for task completion and community incentives.

Expected ecosystem value includes:

- new wallet creation through streamlined onboarding
- increased NIM transaction volume through micro-rewards
- stronger utility and visibility for NIM payments
- broader Telegram-native ecosystem participation

## MVP Goals

The MVP is focused on validating product demand and transaction activity with a lightweight but functional release.

Planned MVP outcomes:

- 2,000 to 5,000 onboarded wallets
- 20,000 or more NIM transactions
- 500 or more completed tasks
- 50 or more active task creators

## Scope of Work

The 6-week MVP includes:

### 1. Telegram Bot Core

- account entry flow
- task discovery
- task participation and submission
- notifications and status updates

### 2. Nimiq Wallet and Payout Layer

- wallet onboarding flow
- reward disbursement logic
- payout tracking

### 3. Task Marketplace System

- task creation
- task listing and filtering
- submission management

### 4. Verification and Moderation

- AI-assisted validation for simple tasks
- anti-spam controls
- reputation scoring

### 5. Public Beta Readiness

- testing
- optimization
- launch preparation
