# NimiqEarn Quest

Supporting repository for the Nimiq ecosystem proposal for **NimiqEarn Quest**.

## Overview

NimiqEarn Quest is a Telegram-native task and bounty marketplace designed to help users earn instant NIM rewards for completing microtasks. The project focuses on simple onboarding, mobile-first participation, fast payouts, and lightweight task verification.

## Repository Purpose

This repository currently serves as proposal support documentation for the MVP grant application. It includes:

- the project support document
- MVP scope and delivery milestones
- ecosystem impact summary
- founder and execution background
